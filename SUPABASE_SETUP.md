# Supabase Setup (Simple)

Use this once, then your app supports accounts + cloud data.

## 1) Create Supabase Project

1. Go to Supabase and create a new project.
2. Open **Project Settings -> API**.
3. Copy:
   - **Project URL**
   - **anon public key**

## 2) Add Vercel Environment Variables

In your Vercel project settings, add:

- `SUPABASE_URL` = your Supabase project URL
- `SUPABASE_ANON_KEY` = your Supabase anon key

Redeploy after adding env vars.

## 3) Create Database Table + Security

In Supabase SQL editor, run:

```sql
create table if not exists public.planner_year_data (
  id bigint generated by default as identity primary key,
  user_id uuid not null references auth.users(id) on delete cascade,
  year int not null,
  data jsonb not null default '{}'::jsonb,
  updated_at timestamptz not null default now(),
  unique (user_id, year)
);

alter table public.planner_year_data enable row level security;

create policy "Users can read own planner data"
on public.planner_year_data
for select
using (auth.uid() = user_id);

create policy "Users can insert own planner data"
on public.planner_year_data
for insert
with check (auth.uid() = user_id);

create policy "Users can update own planner data"
on public.planner_year_data
for update
using (auth.uid() = user_id)
with check (auth.uid() = user_id);
```

## 4) Enable Email Login

In Supabase:

- Go to **Authentication -> Providers**
- Make sure **Email** is enabled

Optional:
- Turn off "Confirm email" during testing if you want instant sign-in.

## 5) Done

Open your app:

- If env vars are missing, it runs in local mode.
- If env vars are set, users can sign up/sign in and data syncs by account.
